在一年一度 Build 2026 開發者大會上，微軟揭曉對於未來 AI 所抱持的願景，推出專為「代理程式優先」（agent-first）新時代打造的全新裝置生態系統平台，它的核心理念不再侷限於單一硬體外型，而是創造一個能將 AI Agent 延伸至各種裝置的作業系統，讓運算能力和 AI Agent 能更貼近使用者的實際需求與所在情境。

微軟願景的專案代號為「Project Solara」，正在朝此方向前進，並在 AOSP（Android Open Source Project，Android 開放原始碼計畫）基礎上打造一套全新、輕量且安全的企業級作業系統，而非採用自家 Windows，微軟稱此平台稱為 MDEP（Microsoft Device Ecosystem Platform）。
MDEP 被設計成存在於無形的作業系統，內含一個能夠動態載入並為多款雲端 Agent 量身打造的 Agent Shell。它不是用於執行傳統應用程式的平台，而是讓 AI 透過一個用戶可進行互動的自適應存取層（adaptive access layer），代替你與各項服務和任務進行接洽。
「為了實現全新的時代，我們將推出一個從晶片到雲端的整合平台，代號為 Project Solara，從一開始便是為了打造代理程式優先的使用體驗，以及這些體驗所能催生出的全新裝置型態而設計。」微軟應用科學小組 CVP 暨技術研究人員 Steven Bathiche 表示，「Project Solara 正是為這個代理程式優先的全新時代量身打造，它將建立硬體和軟體要求，以滿足企業在管理、安全及隱私方面的需求，同時確保提供關鍵的用戶體驗。」
「未來全新的裝置並非用於執行傳統應用程式，它們是為代理程式而設計的」，Steven Bathiche 表示，「這項轉變讓我們在使用者介面上擁有更大的彈性，因為使用體驗本身可依據裝置、螢幕大小、內容，甚至是互動方式來自行調整，無論是視覺、語音、觸控或者多模態。」
實際上，微軟為 Project Solara 設計的概念產品提供公司內部數百名員工使用，包括一款「Desk Concept」和另一款「Badge Concept」。聯發科和高通則是第一批與微軟合作、支援 Project Solara 的合作夥伴，分別為概念產品提供運算晶片，從最初的概念設計開始參與，未來將擴展至不同裝置外形和尺寸。
首先，微軟與聯發科設計、搭載聯發科物聯網晶片的「Desk Concept」，看起來像是具備觸控螢幕的智慧音箱，可回應語音指令，並能獨立使用、搭配 Windows 電腦使用，甚至外接顯示器透過 Windows 365 成為雲端電腦。這款裝置還配備隱私鎖按鍵、麥克風和揚聲器、2 個 USB-C 連接埠，支援 Hello for Business 人臉驗證、Wi-Fi 和藍牙無線連接。
有別於常見智慧音箱的通用用途，「Desk Concept」專為每個組織自己的 AI Agent 而設計，由企業 IT 部門管理和維護。
▲ Desk Concept。
微軟與高通設計的「Badge Concept」像是比較厚實的員工識別證，可隨身佩戴或放入口袋，具備高通穿戴式晶片以及觸控螢幕、指紋感應器、側邊鏡頭、麥克風、揚聲器，支援 Wi-Fi、藍牙、GNSS、5G 無線連接。
微軟舉例醫療機構的場景下，「Badge Concept」內建專為醫護人員設計的 AI Agent，能以鏡頭掃描患者的 QR Code，螢幕顯示就醫、轉診或用藥紀錄，記錄生命體徵，提供醫護人員專用因此不易產生安全和隱私問題。
▲ Badge Concept。
根據外媒 GeekWire 報導，微軟不打算直接對外發售上述兩款產品，它們將是參考設計，微軟希望其他硬體製造商能夠開發出類似用途、廣泛使用的產品。
